# Budget App

A simple Python Budget App that helps users manage income, expenses, and track their remaining balance.

## Features

✅ Add income  
✅ Add expenses  
✅ Calculate remaining balance  
✅ View transaction history  
✅ Easy budget tracking  
✅ Simple command-line interface (CLI)  

## Project Structure

```bash
Budget-App/
│
├── main.py             # Main application
├── budget.py           # Budget functions
├── README.md           # Project documentation
└── requirements.txt    # Dependencies (if any)
```

## Installation

Clone the repository:

```bash
git clone <repository-link>
```

Go to the project folder:

```bash
cd Budget-App
```

Run the program:

```bash
python main.py
```

## How It Works

1. Add your income
2. Add expenses
3. The app calculates your remaining budget
4. View your financial summary

## Functions

### Add Income

```python
add_income(amount)
```

Adds income to the budget.

### Add Expense

```python
add_expense(amount)
```

Records an expense.

### Check Balance

```python
check_balance()
```

Displays remaining balance.
